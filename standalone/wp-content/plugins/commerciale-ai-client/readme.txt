Area cliente, Stripe Checkout e provisioning licenze per Commerciale AI.

== Description ==

Collega un sito WordPress al backend Commerciale AI e a Stripe per vendere
abbonamenti annuali e sincronizzare automaticamente le licenze.

== Installation ==

1. Attiva il plugin.
2. Apri Impostazioni > Commerciale AI.
3. Configura API, Stripe e webhook.
4. Esegui il test connessioni.
